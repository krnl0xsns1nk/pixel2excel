# Pixel2Excel

Convert handwritten grade tables into editable Excel files using AI.

## What it does

- Upload a photo of a handwritten grade table
- The system extracts the numbers automatically
- You can review and fix any mistakes
- Export the result as an Excel (.xlsx) file

## Why this exists

Teachers spend time rewriting grades from paper into spreadsheets.  
This tool reduces that work to a few seconds.

## How to use

1. Upload a clear photo of the grade table
2. Wait for AI processing
3. Review extracted values
4. Download Excel file

## Tips for best results

- Use clear handwriting
- Keep numbers inside table cells
- Take a straight photo
- Avoid shadows or blur

## Important

- This is a beta version
- AI may make mistakes, always review results
- Only upload grade tables (no sensitive data)

## Tech (optional section)

Built with Node.js, Express, and Google Gemini API.
